# 咸鱼桑 · Cinematic Photo Archive

这是一个为个人摄影回忆设计的 GitHub Pages + Supabase 静态网站。

## 这版与旧测试站的关系

- 旧站继续保留，不需要删除，也不要覆盖。
- 新站建议新建独立 GitHub 仓库 `cinematic-archive`。
- 新站默认继续读取旧站已经在使用的同一个 Supabase `photos` 数据表和 `photos` Storage bucket。
- 因此你已经上传的照片会直接出现在新站，不需要重新上传，也不会复制一份照片占用存储。
- 两个网站只是不同的“视觉外壳”，照片数据是共享的。以后在任一后台新增/删除照片，两个网站都会看到变化。

## 已整合之前遇到的问题

1. 档案页不显示原始文件名或 `DSC_xxxx`。
2. 档案和详情页都不强制裁切照片。
3. EXIF 与辅助信息字号更大、对比更高。
4. 详情页照片按左 / 右轮次排列，中间有动态时间线。
5. 首页动态读取 Supabase 后立即显示，不会因为 reveal 动画而保持透明。
6. 后台可选择已有摄影集继续追加照片，也可明确新建摄影集。
7. 上传时浏览器本地读取 EXIF，不保存 GPS；上传的是最长边约 2560px 的网页 JPEG。
8. 数据页保留机身、镜头、焦段、光圈、ISO、年份等统计。
9. 新站不需要 Node、npm、服务器或命令行。

## 视觉方向

采用“电影化摄影档案”方向：深色背景、强排版、首字符斜体/倾斜处理、胶片轨道、页面转场、自定义光标、动态时间线与沉浸式大图浏览。设计语言受到 Jason Bergh 网站的电影感与连续流动式作品浏览启发，但页面、排版和交互均为本项目重新设计。

## 你唯一需要改的文件

`assets/js/config.js`

把旧测试站里已经可用的 `supabaseUrl` 与 `supabaseKey` 两个值复制过来即可。不要复制 Secret key。

详细步骤请打开 `部署说明.html`。
