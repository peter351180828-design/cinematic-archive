本版变化

  • 档案页删除「索引」模式，只保留图片浏览；卡片不再重复显示镜头/快门等 EXIF。
  • 首页 Hero 会从最新摄影集中选择最接近当前屏幕比例的照片；比例差异较大时使用完整图像 + 模糊背景，不硬裁切主体。
  • 首页文字改为暖金色；顶部 UI 改成 WORK / ARCHIVE / DATA / ABOUT / MANAGE。
  • 管理后台新增 English Display Name，可保存英文用户名。设置保存在 Supabase Storage 的 site/site-settings.json，无需新建数据库表。
  • 照片管理缩略图使用方形相册格：背景用同图模糊填充，前景完整 contain 显示，避免竖幅人像被切掉头部。
