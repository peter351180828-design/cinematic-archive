电影感 UI + 批量照片管理升级

这个升级包专门用于你已经部署成功的 Cinematic Archive。它不会覆盖 assets/js/config.js，所以你现有的 Supabase URL、Publishable key 和照片数据不会被动到。

需要替换的 7 个文件

index.html
project.html
admin.html
assets/css/site.css
assets/js/archive-data.js
assets/js/admin.js
assets/js/site.js

GitHub 网页操作

  1. 打开新站 GitHub 仓库。
  2. 分别进入对应路径，把上面 7 个文件替换为本升级包里的同名文件。
  3. 每次替换后点击 Commit changes。
  4. 全部完成后等待 GitHub Pages 自动发布。
  5. Windows 按 Ctrl + F5；Mac 按 Command + Shift + R 强制刷新。

首页变化

恢复到最初那版的设计骨架：全屏 Hero、顶部三段式导航、Creative mode、Film rails，以及“作品 / 精选”的 Slider / List 双模式。摄影集在横向 Slider 中浏览，滚轮、触控板和拖动都可以横向切换。

详情页变化

取消之前的左右交替时间线。照片按拍摄时间纵向自然展开、居中显示，并保持原始比例；EXIF 作为照片下方的信息带，不裁切照片。

照片管理变化

后台“照片管理”会先选择摄影集，再显示缩略图网格。每张缩略图右上角都有圆形勾选框。

  • 点击缩略图或勾选框：选择 / 取消选择。
  • “全选当前摄影集”：一次选中当前筛选出的全部照片。
  • “取消选择”：清空选择。
  • “删除所选”：批量删除数据库记录和 Storage 图片，并有二次确认。
  • “编辑”：仍可修改标题、摄影集和备注。
重要：不要用这个升级包替换 assets/js/config.js。你的 Supabase 配置继续沿用现在已经工作的那一份。
