CINEMATIC PHOTO ARCHIVE / 零基础部署说明

新站单独部署，
旧站完全保留。

这次不动你现在的 Peter.github.io 测试站。我们另外创建一个 GitHub 仓库作为正式电影感网站，但继续读取你已经上传到 Supabase 的照片，所以不需要重新上传 52 张，也不增加一份云端照片存储。

00

先确认：不要删除旧站

你现在的旧测试站继续留在 GitHub。下面所有操作都在一个新的仓库里完成。

旧站：继续做测试。新站：作为 Jason Bergh 方向的正式视觉站。两个站共享同一份照片数据。

01

解压我给你的 ZIP

下载并解压 xianyusang_cinematic_archive.zip。打开文件夹后，你应该直接看到：

index.html
project.html
archive.html
stats.html
about.html
admin.html
assets/
setup/
README.md
部署说明.html

上传 GitHub 时要上传这些“解压后的文件和文件夹”，不要直接上传 ZIP。

02

GitHub 新建仓库

打开 GitHub。右上角点 ＋ → New repository。

Repository name 填：

cinematic-archive

选择 Public，然后点 Create repository。其他选项先不要勾。

03

把新站文件上传进去

新仓库创建后，在蓝色 Quick setup 区域点击 uploading an existing file。

把解压文件夹里的全部内容拖进去。确认上传列表里同时存在：

assets/
setup/
index.html
admin.html
...

滚到底部点 Commit changes。

04

复制旧站已经成功的 Supabase 配置

打开你旧站的 GitHub 仓库 Peter.github.io。

依次点击：

assets → js → config.js

找到已经能正常工作的两行：

supabaseUrl: 'https://xxxxxxxx.supabase.co',
supabaseKey: 'sb_publishable_xxxxxxxxx',

把这两个值复制下来。

只复制 Publishable key。绝对不要复制 Secret key。

05

把两个值填进新站

回到新仓库 cinematic-archive。

点击：

assets → js → config.js → 铅笔 Edit

把占位内容替换为你刚复制的真实值：

supabaseUrl: 'https://你的项目ID.supabase.co',
supabaseKey: 'sb_publishable_你的完整key',

如果你想修改名字，也可以同时改：

siteName: '咸鱼桑',
englishName: 'XIAN YU SANG',

然后点击 Commit changes。

06

这次 Supabase 不需要重新设置

因为新站默认继续使用旧站已经成功运行的：

  • photos 数据表
  • photos Storage bucket
  • 你现有的登录账号
  • 已经修好的 RLS 权限

所以不要重新建 Bucket，也不要重新运行 SQL。你原来的照片会直接被新站读取。

07

开启 GitHub Pages

新仓库顶部点击 Settings → 左侧 Pages。

在 Build and deployment 里：

Source → Deploy from a branch
Branch → main
Folder → /(root)
Save

等待大约 1–3 分钟。

08

打开新网站

你的 GitHub 用户名目前是 peter351180828-design，所以新站地址应为：

https://peter351180828-design.github.io/cinematic-archive/

后台：

https://peter351180828-design.github.io/cinematic-archive/admin.html

仍然使用你原来 Supabase 的邮箱和密码登录。

09

确认旧照片已经出现

打开新站首页。正常情况下，不需要重新上传，原来 Supabase 里的摄影集会直接出现在电影感首页。

再检查：

  • 首页：摄影集有封面
  • 档案：不显示 DSC 文件名，照片不裁切
  • 详情：左右轮次排列，中间动态引导线
  • 数据：总数、设备、焦段等统计可见
10

以后追加照片

进入新站 admin.html。

上传区会先显示已有摄影集，例如：

ChinaJoy 2026 · 52 张
＋ 新建摄影集

选择已有摄影集后上传，照片会继续追加到这个摄影集，不会每次新建一个同名系列。

11

如果新站显示“尚未连接”

最常见原因只有一个：新仓库的 assets/js/config.js 还没有复制正确。

直接在浏览器打开：

https://peter351180828-design.github.io/cinematic-archive/assets/js/config.js

确认里面已经能看到真实的 supabase.co URL 和 sb_publishable_ key，而不是 PASTE_ 开头的占位文字。

12

如果看到旧页面

GitHub Pages 更新后浏览器可能还缓存旧文件。强制刷新：

Windows：Ctrl + F5
Mac：Command + Shift + R
13

以后想把新站变成主站

先不用现在做。等新站稳定后，我们可以再把它迁移到根地址或自己的域名。当前阶段保持两个站并存最安全。

备用：如果未来你新建完全独立的 Supabase 项目，才使用 setup/01_fresh_supabase.sql。现在不需要。
